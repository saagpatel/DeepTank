# DeepTank PM Docs Closeout Kit

This folder is a lean, decision-ready closeout pack for DeepTank.

## Use This In 4 Steps

1. Follow the sequence in `closeout-workstream-plan.md`.
2. Each owner updates only their template once per cycle.
3. PM reviews only exceptions, decisions, and escalations.
4. Run `checklists/final-closeout-checklist.md` to close the workstream.

## Canonical Docs In This Kit

- `status/product-status.md`
- `runbooks/operator-runbook.md`
- `releases/release-notes.md`
- `onboarding/onboarding-guide.md`
- `support/support-playbook.md`
- `checklists/final-closeout-checklist.md`

## PM Intervention Rules

- PM is required only for:
  - unresolved priority conflicts
  - scope change decisions
  - go/no-go release decisions
- Everything else is owner-driven by the teams listed in the plan.
